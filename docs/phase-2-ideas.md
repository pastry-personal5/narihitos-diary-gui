# Phase 2 Ideas

Status: Ideas only; not yet scheduled or approved as milestones.

These items provide a starting point for planning Phase 2 / Diary v2.0.0.
Their scope, priority, sequence, and acceptance criteria have not yet been
defined.

## Candidate areas

- **Further refactoring**
  - Continue simplifying the codebase and strengthening its boundaries based
    on lessons learned during Phase 1.

- **GUI polish and enhancements**
  - Review the GUI according to established UI/UX principles.
  - Identify and address issues related to usability, consistency, visual
    hierarchy, feedback, accessibility, and interaction design.
  - Implement broader GUI improvements identified during the review.

- **Analytics and Insights**
  - Add analytics based on diary content and user activity.
  - Present useful findings to the user through an **Insights** experience.

- **Dedicated calendar view**
  - Provide a calendar-focused view for browsing and navigating diary entries
    by date.

- **Paragraph Review improvements**
  - Resolve known issues in Paragraph Review.
  - Improve its workflow and interaction model.

- **Draft-generation prompt improvements**
  - Resolve shortcomings in the current draft-generation prompts.
  - Improve prompt quality and consistency, as well as the usefulness of the
    generated drafts.

## Planning notes

These ideas should be refined into an ordered Phase 2 plan after Phase 1
release qualification and any required owner decisions. In particular, the
scope of the analytics and Insights features, the information architecture for
the calendar view, and the approach to prompt management and evaluation need
to be designed before implementation.
