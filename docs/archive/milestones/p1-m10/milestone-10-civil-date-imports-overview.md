# P1-M10: Civil-date imports and timestamp resolution overview

Status: Done (2026-11-05)

Turn the read-only source scans of P1-M9 into date imports: capture the system IANA zone once, include D-1, D and D+1 by civil date in that zone, and let the user resolve timestamp disagreements by an explicit, digest-bound choice that never rewrites a source. The work plan is [milestone-10-civil-date-imports-architecture.md](milestone-10-civil-date-imports-architecture.md). Contracts: [import zone and calendar boundaries](../../../architecture/sources-and-dates.md#import-zone-and-calendar-boundaries), [parsing and timestamps](../../../architecture/sources-and-dates.md#parsing-and-timestamps), [persistence tables](../../../architecture/domain-and-persistence.md#sqlite-responsibilities).
