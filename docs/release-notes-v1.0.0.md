# Version v1.0.0

Status: Draft release note

Narihito's Diary v1.0.0 is the first personal macOS release for organizing
diary entries and related source snippets in one desktop workspace.

## Highlights

- Create and edit Draft and Entry content with durable autosave and recovery.
- Import, read and save supported Narihito source snippets while preserving
  their producer-owned metadata and audio.
- Use optional AI Chat, Draft candidate generation and Paragraph Review with
  guarded accept/reject workflows.
- Export saved Authentic entries through iCloud and Notion, and upload published Illustrated diaries to ordered, stable Notion day pages with resized JPEG photos. Configure independent roots with `notion.pages`; legacy `notion.root_page_id` requires explicit migration and server restart.
- Manage settings, AI-agent status, keyboard shortcuts, diagnostics and
  recoverable source Trash operations from the app.

- Create a separate Illustrated diary from saved Authentic text, follow photo progress/cancellation, read it in a rendered read-only tab, replace or confirm deletion, and check image engines in Settings.

## Availability and limitations

Version v1.0.0 is scoped to the owner's Apple Silicon Mac. Public distribution,
Intel support, signing, notarization and App Store delivery are outside this
release. Some workflows depend on configured external services or locally
available AI agents. The active [release qualification checklist](phase-1/milestone-32-personal-release-overview.md)
records the remaining artifact and automated acceptance evidence; this note does
not claim that qualification is complete.
