# UX GUI

Status: Active

This document specifies the target interface from the approved original layout and engineering interaction contracts. Product scope is in [product-behavior.md](product-behavior.md); component vocabulary is in [ux-terms.md](ux-terms.md). These are planned behaviors, not evidence of an implemented app.

## Navigation and actions

Use the [Standard Layout](ux-information-architecture.md): Main Toolbar Strip, left Icon Bar/Explorer, Tabbed Editor and AI Chat. The toolbar shows the selected civil date, Connection status, Save status, AI activity and available Create Empty/Save/Generate/Export actions. Disabled actions explain their missing capability or invalid state. Settings has a sidebar: a redacted status section (with the result of explicit config reload), Writing Language, and Keyboard Shortcuts, a table of Action, Original shortcuts, Current shortcuts and Info where the user edits bindings, per [keyboard shortcuts](architecture/keyboard-shortcuts.md). Writing language initially uses the Mac's preferred language, persists across sessions and applies to new AI runs. Credential editing remains in the private YAML outside the GUI; edited preferences persist in [user settings](architecture/user-settings.md).

Date selection drives a captured-timezone import of D-1/D/D+1. Snippet displays source/local-date groups, Snippet checkbox inclusion, parse/availability warnings and an explicit refresh action. Newly imported eligible snippets start checked; re-import leaves unchanged snippets visible and preserves their selection. Focusing/opening a snippet and using its Snippet checkbox are separate actions. Conflicting timestamps display both interpretations and an explicit authority choice; unresolved/undated snippets cannot enter generation.

The Tabbed Editor shows Markdown body text. Sources require explicit Save; unsupported write variants remain readable with a reason. Authentic autosaves, and Draft/Entry navigation opens the same Editor tab/buffer. **Create Empty** immediately saves an empty Authentic file for the selected date and opens its editable buffer; it requires neither snippets nor an agent. The saved empty draft appears in Draft/Entry after restart. Disable it for an existing file or dirty/in-flight creation state and never clear existing text through this action. Candidate Editor tabs are read-only transient suggestions. Editor tab switching preserves editor selection/undo and pending Authentic saves. A source delete action lives in the Snippet hierarchy and previews the exact snippet/validated audio set in a Confirmation dialog. Partial results list moved, failed and uncertain members; retry does not repeat completed moves.

## Save, review and transition feedback

Save status shows dirty/saving/saved/failed/conflict based on the acknowledged revision, not a timer. Date change and close wait for pending Authentic saves and admitted source saves. Dirty source buffers require explicit Save or Discard; close never silently saves them. Failed saves retain the editor, offer retry and explicit discard, and block the transition. Forced process loss can lose client-only edits. Optional export failure does not change local saved status.

Generation requires at least one selected eligible snippet; otherwise Generate explains why it is disabled. It uses the Profile selector and a count (default three, range one to five); runs are sequential with visible progress/cancel and independent candidate outcomes. Review flushes Authentic and verifies the captured generation baseline still matches the saved file; stale candidates require regeneration. Manual Authentic editing pauses while Review controls (per-paragraph Accept/Reject) are active; structural Markdown units are labeled. Accepted changes become saved only after acknowledgement. Rejected/pending changes do not alter the file. External changes invalidate remaining review; ending review or closing waits for admitted accepts and discards pending suggestions while preserving accepted text. The exact alignment contract is in [editing and agents](architecture/editing-and-agents.md#paragraph-alignment-and-review).

Changing the selected date keeps generation running in the background for its original date and captured context. Progress/completion names that date and never switches the editor automatically. Returning to the original date exposes its session candidates; stale ones explain why regeneration is needed. The single active agent run still applies across dates. Close cancels generation and discards all app-owned transient results; date changes end the outgoing paragraph review but preserve background candidate results.

The [background AI experience](architecture/ai-job-experience.md) keeps a persistent AI activity summary in the Main Toolbar Strip, with expandable stage/count/elapsed/Cancel details and contextual states in Draft/AI Chat. Generate/Send responds immediately with a submitting state; server admission and inference completion are distinct. Users can continue ordinary editing, autosave, navigation and Create Empty. Another AI request explains the occupied run instead of silently queueing. Completed results remain discoverable through a Results badge and one polite Completion message with View results; it never changes focus or the active editor automatically. No macOS notification or sound is used. Quiet-agent, stopping and disconnected states stay explicit, without invented percentages, time estimates or reasoning traces. If the saved entry changes during generation, the owner requires regeneration before review.

AI Chat uses the Profile selector for one profile per session and sends the current active editor snapshot, including visibly identified unsaved edits. Missing profiles leave editing/import available. Exceeding a context limit requires a smaller context or new chat; never silently drop messages. Closing the app discards its chat/candidates, while installed CLI/provider retention follows their own configuration/account policy.

Profile selection includes configured Codex, Claude Code, Qwen Code and Apple Foundation Models aliases. The Apple profile reports native availability, including ineligible device, Apple Intelligence disabled or model not ready; it does not request a CLI login or executable. Unavailable profiles explain their state and preserve editing. Selecting another profile is explicit, including after context, language or refusal errors; no automatic cloud fallback.

Export uses a selected saved revision and reports its own pending/succeeded/conflict/uncertain status. Replacing externally changed iCloud/Notion output requires a fresh explicit Export preview and confirmation; another remote change invalidates that confirmation. A local iCloud write does not claim cloud upload completion. Structural/ambiguous Notion conflicts require inspection rather than an automatic re-sort.

## Input and accessibility

All icon controls have text tooltips and accessible names from [UX terms](ux-terms.md). Use keyboard-operable date cells, labeled grouped checkboxes/disclosures and Pane separators with visible focus. Arrow navigation moves within the date grid using civil calendar arithmetic; Enter selects, and a skipped date gives a validation message. Preserve focus on Editor tab changes, restore dialog/palette focus to its invoker, and keep snippet focus independent of inclusion.

Factory-default shortcuts include Cmd+Shift+P (command palette) and Cmd+S (the same Save/flush action as the toolbar); all bindings are user-editable and come from the shared action registry. Do not intercept normal editing/IME composition shortcuts. Save debounce waits for composition completion. SF Symbols use the native runtime route in [platform strategy](architecture/configuration-and-exports.md#version-and-platform-strategy), with accessible text available for unsupported symbols. Detailed colors/typography remain visual design work; this contract does not imply a new theme or component library.

Actual WKWebView tests must cover keyboard-only workflows, VoiceOver names/order, Korean/Japanese IME, Editor tab/focus/undo preservation, Pane separator resize, long documents and large snippet groups. Mocks cannot prove native accessibility or composition behavior.
